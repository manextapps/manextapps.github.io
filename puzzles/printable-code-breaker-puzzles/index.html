Printable code breaker puzzles with answers

Each puzzle is a locked code and a few old guesses, with a note on how close each guess came. Find the one code that fits every clue. Print the set for a class or a quiet evening, or check your answers right here.

Printing gives you all 20 puzzles without the answers, and the answer key on a page of its own. On screen, type your answer under a puzzle and press Check, or open the step by step answer.

How the clues work

Every puzzle hides a code with no repeated digits. A code can start with 0. Each clue shows a guess and tells you two things about it: how many of its digits are in the code at all, and how many of those sit in the right place.

  • "Exactly 1 digit is correct and in the correct position." One digit of the guess is in the code, in that exact spot. The others aren't in the code.
  • "Exactly 1 digit is in the code but in a different position." One digit is in the code, somewhere else. The others aren't in the code.
  • "None of these digits is in the code." Cross all of them out. This is usually the best place to start.

Clues with bigger numbers work the same way, just with more digits. Every puzzle here has exactly one code that fits all its clues, and you can always reach it by reasoning, without trying codes at random.

A quick method

  1. Cross out the none clues.

    Every digit in a "none of these" clue is gone, everywhere.

  2. Use those cross outs on the other clues.

    Once a clue's dead digits are gone, its count often has only one way to fit.

  3. Place digits by position.

    A digit that's "in the code but in a different position" can't sit where that guess had it.

  4. Try a what if.

    When you're stuck, suppose a digit is in the code and follow the clues. If one breaks, the digit is out.
