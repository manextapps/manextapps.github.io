    How to play

    The vault is locked with a secret code of 3, 4 or 5 digits. No digit appears twice, and a code can start with 0.

    1. Read the clues. Each one tells you how many of its digits are in the code, and how many of those sit in the right slot.
    2. Cross out what can't be true. A clue that says none of its digits is in the code wipes out those digits at once.
    3. Type the one code that fits every clue, then press Open the vault.

    Every vault has exactly one solution, and you can always get there with logic alone. Every vault on this page has been checked against every possible code, so there's never a second answer hiding in there.

    What the clues mean

    Clue saysWhat it means
    None of these digits is in the code.Cross out every digit in that guess. They're gone from every slot.
    Exactly 1 digit is correct and in the correct position.One digit of the guess is in the code, in that exact slot. The others aren't in the code at all.
    Exactly 2 digits are in the code but in different positions.Two digits of the guess are in the code, each in some other slot. The rest aren't in the code.
    Exactly 2 digits are correct in total, of which 1 is in the correct position.Two digits are in the code: one where the guess has it, one somewhere else. The rest aren't in the code.

    Here's the part people miss. Every clue gives the full result for its row, so any digit the clue doesn't count as correct isn't in the code. That makes the clues a lot stronger than they look.

    Hints and notes

    Explain the next step shows one deduction you can make right now, in plain words. Reveal a digit puts one correct digit in its slot and locks it there.

    Hints are free here and there's no limit, but your result counts them. The notes row under the keypad is your scratch pad: tap a digit once to cross it out, twice to mark it as in the code.

    Open the vault with a wrong code and the game tells you which clue your code breaks. It's the quickest way to find the slip in your reasoning.

    About the daily vaults

    You get three vaults a day: 3 digits (Easy), 4 digits (Medium) and 5 digits (Hard). They change at midnight on your device, and everyone gets the same three for the same date, so you can compare with friends. The share button copies your attempts, hints and time. Never the code.

    Want more? Practice vault builds a fresh puzzle of the same size whenever you like.

    Stuck?

    Start with any clue that says none of its digits is in the code. Then look for a clue whose count is already used up. My guide How to solve code breaker puzzles walks through three full puzzles step by step, including the well known lock riddle with 682.

    Questions

    Is this like Mastermind or bulls and cows?

    It uses the same kind of feedback: how many digits are right, and how many are in the right place. The difference is that you don't make the guesses. They're given, with their results, and you work out the code from them.

    Can a code have the same digit twice?

    No. Every digit in a code is different, and so is every digit in each guess.

    Do I need an account?

    No. There's nothing to sign up for. Your streak is saved in your browser only.
